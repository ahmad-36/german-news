## 2. Main findings

1. **Stance labels are per outlet, not per article.** AllSides and Ground News give every
   article its publisher's rating, so a model trained on them learns *who published it*.
   On unseen outlets it scores **30.9%**, statistically **indistinguishable from that
   split's own 28.1% majority baseline** — it carries nothing across outlets.
   ([stance_labels.md](stance_labels.md))
2. **Classifiers rely on the publisher's name.** Swapping the outlet name in the text for
   an opposite-side one shifts the best classifier's prediction by **+31 points** toward
   that side. ([future_directions.md](future_directions.md))
3. **An LLM agrees with the outlet label only 50% of the time.** Fox News is the *most*
   consistent outlet (29% disagreement); "center" is almost never predicted (78%
   disagreement). ([stance_labels.md](stance_labels.md))
4. **Ground News' translation deletes entities** (*Neuer* → "new", *Bayern* → "Bavaria"),
   and its topic tagging demonstrably reads the translated text. Its **clustering
   mechanism is undocumented**, so we cannot say translation happens before clustering —
   which leaves the paper-worthy question open rather than answered: which clustering
   architecture handles multiple languages best?
   ([translation_problem.md](translation_problem.md))
5. **Clustering (German only):** BGE-M3 embeddings score **0.79 F1** against Event
   Registry's own event IDs; our production GDELT clusterer scores **0.45**, losing about
   two-thirds of same-event pairs. Worth noting: on equal input, plain TF-IDF ties BGE-M3 —
   the gain is from using full bodies, not from embeddings. The cross-lingual comparison
   can't be run on the free Event Registry tier. ([future_directions.md](future_directions.md))
6. **Collection is now bounded:** one filtered GDELT week gives **273** German political
   stories with 3+ outlets in ~10 minutes. ([collection_policy.md](collection_policy.md))

## 3. The core problem: no human ground truth

Every downstream task (summaries, stance summary, stance comparison, stance prediction,
clustering) needs human ground truth at the right level. What exists is either
**GPT-generated** (Ground News summaries and comparisons) or **human but per outlet**
(bias labels). See [tasks.md](tasks.md) for which task each gap blocks.

- **Small enough for me alone:** judging ~100 Event Registry clusters; verifying ~100
  Ground News stance comparisons.
- **Needs annotators:** article-level stance labels, and human-written summaries.
